# Lenguajes M2 BUFFER
## Introduccion
En nuestro programa se implemento un buffer de entrada que procesa una cadena , esta cadena la splitea en una lista y luego el buffer va de 10 en 10 procesando la misma. Y luego identifica los tokens que corresponden

Se usan un inicioLexema y avance como centinelas para recorrerla y un lectura para poder recorriendo la lista y verificar cuando termina.


## Instrucciones

- Clonar el repositorio [**Repositorio**](https://github.com/cor22982/Lenguajes)  
- Ir a la rama del repositorio
```
git checkout m2_buffer
```
- Ejecutar archivo python
```
python Buffer.py
```

- Salida
```
Lexema procesado: Esto
Lexema procesado: es
Lexema procesado: un
Lexema procesado: ejemplo
Lexema procesado: eof
```
- Esto se puede simular con distintas cadenas. Pueda cambiarla en la linea
```
entrada = list("Esto es un ejemplo eof")
```
